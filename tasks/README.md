# Task cards

Each part of the lab has one card per partner. Open only your own card for the part you are on.

| Part | Partner A | Partner B | Who pushes first |
| --- | --- | --- | --- |
| 1. Commit and the push race | `part1-A.md` | `part1-B.md` | A |
| 2. A real merge conflict | `part2-A.md` | `part2-B.md` | B |
| 3. AI on a branch | `part3-A.md` | `part3-B.md` | Either (separate branches) |
| 4. Break it, recover it | `part4.md` | `part4.md` | Nobody pushes |
| Finished early? | `bonus.md` | `bonus.md` | |

Three rules for the whole lab:

1. Know your `git status` before an agent touches your files.
2. Never approve an agent's `git push --force`, `git reset --hard` or `git clean -fd`.
3. When something looks wrong, stop and run `git status` before anything else.
